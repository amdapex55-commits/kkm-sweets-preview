# KKM Sweets & Nimco Center — front-end design concept

A ground-up front-end recreation of kkmofficial.com, built for client presentation.
Static HTML / CSS / vanilla JS — no framework, no page builder.

**Live preview:** https://amdapex55-commits.github.io/kkm-sweets-preview/

Photography, logo, prices and contact details belong to KKM Sweets & Nimco Center
and are used here only so the design concept can be judged on its own terms.
